# 408 数据结构（C 语言实现）

本部分用于配合王道 408 数据结构学习。每章先读教材，再独立写接口和核心算法，最后用测试验证。代码按“数据结构定义 → 基本操作 → 核心算法 → 测试”组织。

推荐顺序：01 绪论与复杂度 → 02/03 线性表 → 04/05 栈队列 → 06 串 → 07 树 → 08 图 → 09 查找 → 10 排序 → 11 综合题。

每章目录约定：
- README.md：本章考点、易错点、复杂度
- include/*.h：类型和函数声明
- src/*.c：数据结构与算法实现
- tests/main.c：手写测试和边界测试
- exercises.md：练习映射和自拟题
- notes.md：错题、复杂度、记忆卡片

编译示例：
gcc -std=c17 -Wall -Wextra -pedantic -I include src/*.c tests/main.c -o test.exe

每个算法都记录：输入输出、循环不变式或递归终止条件、最好/平均/最坏复杂度、空间复杂度、是否稳定、是否原地、边界情况。
