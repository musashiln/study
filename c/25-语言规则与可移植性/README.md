# 25 语言规则与可移植性

## 学习目标

掌握声明、定义、初始化、作用域、存储期、链接属性、整数提升、隐式转换、溢出、未定义行为、字节序、对齐和结构体填充。

## 1. 声明、定义和初始化

声明告诉编译器名字和类型；定义会分配存储空间；初始化是在定义时设置初值。

~~~c
extern int counter;       /* 声明，定义在其他源文件 */
int total;                /* 定义，静态对象默认初始化为 0 */
int count = 3;            /* 定义并初始化 */
~~~

同一个外部变量可以有多个声明，但只能有一个定义。头文件放声明，某一个 c 文件放定义。

## 2. 作用域、存储期和链接

作用域决定名字在哪里可见；存储期决定对象什么时候存在；链接属性决定不同源文件的同名标识符是否是同一实体。

~~~c
int global_value;          /* 文件作用域、静态存储期、外部链接 */
static int file_value;     /* 只在本文件可见 */

void f(void)
{
    static int calls;      /* 生命周期贯穿程序 */
    int local;             /* 进入代码块时创建，离开时销毁 */
    (void)local;
    ++calls;
}
~~~

## 3. 整数提升和转换

char、short 等类型参与运算时通常先提升为 int。混合有符号和无符号类型可能产生反直觉结果。平均值要显式转换：

~~~c
double average = (double)sum / (double)count;
~~~

不要依赖隐式窄化转换，重要转换要显式写出。

## 4. 未定义行为

有符号溢出、数组越界、读取未初始化变量、错误格式说明符、非法移位都可能是未定义行为。未定义行为的结果不受标准保证。

- 未定义行为：标准不规定结果。
- 未指定行为：多个结果都允许，标准不要求说明选择。
- 实现定义行为：实现必须选择并记录一种行为。

## 5. 字节序、对齐和填充

多字节整数在内存中的排列可能是小端或大端。结构体可能插入填充字节，sizeof 结果与平台有关。与文件或网络协议交互时，应显式序列化字段，不要直接把结构体内存写出去。

## 操作步骤

1. 手敲 src/main.c。
2. 编译：gcc -std=c17 -Wall -Wextra -Wpedantic -g src/main.c -o .build/ch25.exe
3. 用 sizeof 比较不同字段顺序的结构体。
4. 故意制造越界和未初始化读取，记录编译器和运行时表现。
5. 解释每个错误为什么不能依赖“当前机器刚好能运行”。

## 练习

1. 用 extern 拆分 config.h、config.c、main.c。
2. 写安全平均值函数。
3. 判断 5 段代码中的未定义行为。
4. 记录 CHAR_BIT、sizeof(int)、sizeof(void*)。

## 完成标准

能解释声明/定义的区别，并主动识别溢出、越界、未初始化和格式错误。
