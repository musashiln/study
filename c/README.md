# C 语言跟练项目

依据 [C语言入门到精通，这一篇就够了（13万字笔记）](https://blog.csdn.net/weixin_44617968/article/details/117661182) 整理。按编号学习：先读每章 README，再手动重写 src/main.c，编译运行，记录 notes.md，完成 exercises.md。

编译：gcc -std=c17 -Wall -Wextra -pedantic src/main.c -o main

章节主线：程序基础、注释关键字标识符、数据类型变量常量、输入输出、运算符、流程控制、函数、进制位运算内存、一维/二维数组、字符串、指针、结构体共用体枚举、存储类别与预处理、动态内存与链表、文件、综合项目。

教程原文及示例版权归原作者所有；本项目仅作个人学习整理。


## 嵌入式 C 补充路线

完成基础章节后，建议继续学习：

| 目录 | 主题 |
|---|---|
| 18 | 嵌入式 C 编码规范与资源意识 |
| 19 | 位操作、寄存器模型与 volatile |
| 20 | 编译、链接、启动文件与内存布局 |
| 21 | 中断、并发与状态机 |
| 22 | 外设驱动分层与硬件抽象 |
| 23 | 交叉编译、调试与工程化 |
| 24 | 综合项目：可移植的 GPIO/UART 模拟框架 |

推荐顺序：先完成 01~17 的基础，再完成 18~21，之后选择一块开发板，把 22~24 的模板替换成芯片手册中的寄存器和 SDK API。
