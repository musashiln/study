# 嵌入式 C 学习路线

## 第一阶段：C 基础
完成 01~17，重点是指针、数组、结构体、内存管理、文件和调试。

## 第二阶段：硬件相关 C
完成 18~21，重点是固定宽度类型、位操作、volatile、内存布局、中断和状态机。

## 第三阶段：工程与驱动
完成 22~24，再结合具体芯片学习 GPIO、UART、定时器、ADC、PWM、I2C、SPI、DMA。

## 建议增加的硬件实验

1. LED 闪烁：GPIO 输出、延时、状态机。
2. 按键控制 LED：输入、消抖、中断。
3. UART 回显：串口收发、环形缓冲区。
4. 定时器时钟：周期任务、非阻塞调度。
5. I2C/SPI 传感器：协议时序、驱动分层。
6. DMA 数据采集：缓冲区、并发和缓存一致性。
