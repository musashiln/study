# 01：二级指针与数组下标

练习：[realloc.c](../exec/realloc.c) 中的 `push_back`。传入 `&nums` 是为了让函数能在扩容后更新 `main` 里的数组指针。

- 错误：`*nums[*n] = value;`，等价于 `*(nums[*n]) = value;`。
- 正确：`(*nums)[*n] = value;`，先取出数组指针，再按下标写入。写完再执行 `(*n)++;`。

`[]` 比一元 `*` 优先结合。在 `push_back` 里，参数 `nums` 指向 `main` 里的一个指针变量，`*nums` 才是动态数组的首地址。第一次追加时 `*n == 0`，错误写法碰巧能写到第一个元素；第二次追加时 `*n == 1`，它会先访问 `nums[1]`，越过那个指针变量，导致未定义行为，不一定马上报错。

**怎么排查：** 先按运算符优先级补上括号，再问自己：`[]` 左边到底是数组首地址，还是保存这个地址的变量的地址？

**最小验证：** 初始 `n = 0`、`capacity = 2`，依次追加 `3`、`5`。预期输出 `3 5`，且 `n == 2`、`capacity == 2`。这两次都不扩容，可以单独验证下标写入。
