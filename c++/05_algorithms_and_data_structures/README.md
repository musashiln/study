# 05 - 数据结构与算法

## 阶段目标

理解常用数据结构的实现思想、时间与空间代价，能够为工程问题选择合适的标准容器和算法。重点是分析与选型，不以大量刷题为目标。

## 学习内容

1. **复杂度与分析方法**
   - 时间复杂度、空间复杂度、最好/平均/最坏情况
   - 大 O 表示法、摊还复杂度
   - 基准测试与“先测量再优化”
2. **线性结构**
   - 动态数组、链表、栈、队列、双端队列
   - 环形缓冲区
   - 连续存储、缓存局部性和迭代器失效
3. **关联结构**
   - 哈希表、哈希冲突与负载因子
   - 二叉搜索树、平衡树的概念
   - 堆和优先队列
4. **图与搜索**
   - 图的表示
   - 深度优先搜索、广度优先搜索
   - 最短路径的基础概念
5. **常用算法思想**
   - 线性查找、二分查找
   - 基础排序与 `std::sort`
   - 递归、分治、回溯
   - 贪心和动态规划入门
6. **工程选型**
   - `vector`、`deque`、`list` 的选择
   - `map` 与 `unordered_map` 的选择
   - 数据量、访问模式、内存和实时性约束

## 实践任务

- 手写栈、队列和环形缓冲区，并与 STL 对应容器比较。
- 实现 BFS/DFS 网格寻路。
- 为不同容器编写小型基准测试，记录并解释结果。
- 使用优先队列模拟任务调度。

## 完成标准

- [ ] 能分析一段基础代码的时间和空间复杂度
- [ ] 能解释常用数据结构的核心操作和适用场景
- [ ] 能根据工程约束选择 STL 容器
- [ ] 能实现二分查找、基础排序、BFS 和 DFS
- [ ] 能说明递归、回溯、贪心和动态规划的基本区别
- [ ] 能通过测量而不是猜测评价性能
