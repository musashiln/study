# 00 - 开发环境与工具基础

## 阶段目标

建立可重复的 C++ 开发环境，理解从源代码到可执行文件的基本过程，并能够独立阅读和定位常见编译错误。

主环境为 Windows 上的 GCC/MinGW 与 C++17；进入系统与 ROS 2 阶段前切换或补充 Ubuntu Linux 环境。

## 学习内容

1. **环境与终端**
   - 编辑器、编译器、终端和调试器的职责
   - 路径、工作目录、环境变量和命令行参数
   - UTF-8 编码与 Windows 终端中文输出
2. **最小编译流程**
   - 源文件、目标文件和可执行文件
   - 预处理、编译、汇编、链接的基本过程
   - Debug 与 Release 构建的区别
3. **编译器使用**
   - `-std=c++17`、`-Wall`、`-Wextra`、`-Wpedantic`
   - 阅读 warning、error、文件名和行号
   - 区分编译错误、链接错误和运行时错误
4. **编辑器与调试**
   - 配置补全、构建任务和启动配置
   - 断点、单步执行、变量观察和调用栈
5. **Git 入门**
   - 仓库、工作区、暂存区和提交
   - `status`、`add`、`commit`、`log`、`diff`
   - `.gitignore` 与小步、清晰提交

## 实践任务

- 在终端中独立编译并运行 Hello World。
- 故意制造语法错误、未定义引用和运行时错误，记录三者差异。
- 使用断点查看 `main` 中变量的变化。
- 建立一次规范 Git 提交，确认构建产物未被跟踪。

## 完成标准

- [ ] 能说明编辑器、编译器、链接器和调试器各自负责什么
- [ ] 能从零执行编译命令，并解释主要参数
- [ ] 能根据错误信息找到对应文件和行号
- [ ] 能区分编译、链接和运行时错误
- [ ] 能使用断点、单步和变量观察完成一次排错
- [ ] 能完成基本 Git 提交并正确使用 `.gitignore`
