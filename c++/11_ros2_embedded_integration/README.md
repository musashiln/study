# 11 - ROS 2 与嵌入式系统集成

## 阶段目标

把 ROS 2 上位机与 MCU 下位机连接成一个可靠系统，明确实时控制与非实时通信的边界，并完成可测试、可观测、可恢复的机器人项目。

## 参考架构

```text
ROS 2 上位机
  |  驱动节点 / ros2_control / 诊断
  |  UART、CAN、USB 或 Ethernet
MCU 下位机
  |  实时采集 / 控制 / 安全保护
  |  编码器、电机、IMU 与其他传感器
```

## 学习内容

1. **职责与接口设计**
   - 上位机：规划、可视化、配置、记录和非实时算法
   - 下位机：高频采样、闭环控制、执行器安全和硬实时任务
   - 接口版本、单位、坐标系、范围和故障语义
2. **传输与协议**
   - UART、CAN、USB、Ethernet 的选型
   - 消息帧、转义、长度、序号、CRC 和版本
   - 超时、重传、去重、心跳和断线重连
   - 带宽、延迟、抖动和总线负载预算
3. **时间与数据一致性**
   - 单调时钟、ROS 时间和 MCU 计时器
   - 时间同步、采样时间戳和传输延迟
   - 序列号、乱序、丢包和陈旧数据
4. **ROS 2 硬件接入**
   - 编写 ROS 2 驱动节点
   - 串口/CAN 收发线程与 ROS 回调隔离
   - `ros2_control` Hardware Interface
   - micro-ROS 的架构、适用场景和资源约束
5. **安全与故障处理**
   - 命令超时、失联停车、限幅和急停
   - 看门狗、故障码、降级模式和恢复策略
   - 通信失败不得阻塞实时控制环
6. **测试与观测**
   - 协议编码/解码单元测试
   - MCU 模拟器或虚拟串口集成测试
   - 故障注入：丢包、延迟、乱序、断线、错误 CRC
   - ROS 诊断、日志、rosbag 和性能指标

## 毕业项目建议：ROS 2 智能底盘

- MCU 读取编码器和 IMU，执行电机速度 PID。
- MCU 通过 UART 或 CAN 上报带时间戳的状态。
- ROS 2 驱动节点解析数据并发布里程计、IMU 和诊断信息。
- 使用 `ros2_control` 接收速度命令并下发左右轮目标值。
- 实现心跳、命令超时、CRC、序号、看门狗和失联停车。
- 仿真或回放环境可在没有真实硬件时运行上位机测试。
- 记录端到端延迟、控制周期抖动、丢包率和故障恢复时间。

## 完成标准

- [ ] 有清晰的上位机/下位机职责和接口文档
- [ ] 协议支持版本、校验、序号、时间戳和错误恢复
- [ ] 实时控制不依赖 ROS 2 通信及时返回
- [ ] 驱动节点或 Hardware Interface 有自动化测试
- [ ] 能注入并处理丢包、断线、延迟和损坏数据
- [ ] 系统具备命令超时、看门狗、限幅和安全停车
- [ ] 能使用日志、诊断和 rosbag 定位端到端故障
