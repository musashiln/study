# 10 - 嵌入式开发

## 阶段目标

理解 MCU 从启动到运行的基本机制，能够驱动常见外设、设计可靠通信协议、使用调试工具排查故障，并在 RTOS 中组织实时任务。

## 学习内容

1. **电子与硬件基础**
   - 电压、电流、电阻和功率基础
   - 数字电平、上拉/下拉、推挽/开漏、电平转换
   - 按键去抖、ADC、PWM
   - 原理图、数据手册和参考手册阅读
2. **MCU 与构建链路**
   - CPU、寄存器、Flash、RAM 和内存映射
   - 交叉编译、启动文件、中断向量表
   - Linker Script、段、栈与堆
   - C 与 C++ 混合编程、`extern "C"`
3. **嵌入式 C/C++ 约束**
   - 固定宽度整数、位运算、宏和位域
   - `volatile`、`const` 与内存映射寄存器
   - 动态内存、异常、RTTI 的限制与取舍
   - 静态分配、确定性、状态机和 RAII 的适用方式
4. **外设与中断**
   - GPIO、定时器、中断、ADC、PWM
   - UART、I2C、SPI
   - DMA、看门狗和低功耗基础
   - 中断服务程序最小化与主循环/任务协作
5. **工业与机器人通信**
   - CAN / CAN FD
   - RS-485、Modbus 基础
   - USB 和 Ethernet 基础
   - 帧格式、字节序、CRC、超时、重试和状态机解析
6. **调试与可靠性**
   - SWD/JTAG、断点、寄存器和内存查看
   - HardFault 与异常信息分析
   - 逻辑分析仪、示波器和串口日志
   - Bootloader、固件升级和回滚概念
7. **RTOS / FreeRTOS**
   - Task、Queue、Semaphore、Mutex
   - Event Group、软件定时器
   - 中断与任务通信
   - 优先级反转、调度、栈使用量
   - 静态内存分配和实时性分析

## 建议实践顺序

1. GPIO 输入输出、按键去抖和定时器闪灯。
2. UART 命令行与环形接收缓冲区。
3. 使用 I2C/SPI 读取真实传感器。
4. 使用 DMA 采集或发送数据。
5. 设计带 CRC、超时和版本号的通信协议。
6. 使用 CAN 控制模拟执行器或与另一节点通信。
7. 在 FreeRTOS 中拆分采集、控制、通信和监控任务。
8. 故意制造 HardFault、栈不足和优先级问题并完成排查。

- [ ] 能使用 SWD/JTAG 与硬件工具定位故障
- [ ] 能设计职责清晰且避免优先级问题的 RTOS 应用
