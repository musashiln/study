# 03 - 面向对象与资源管理

## 阶段目标

使用类表达清晰的不变量和职责，理解对象生命周期，并通过 RAII 安全管理资源。学习继承和多态，但优先考虑组合、值语义和泛型。

## 学习内容

1. **类的基础**
   - 类、对象、成员、访问控制和封装
   - 构造函数、析构函数、初始化列表
   - `this`、静态成员、`const` 成员函数
2. **对象语义**
   - 拷贝构造、拷贝赋值
   - 移动构造、移动赋值
   - Rule of Zero / Three / Five
   - 值语义、所有权和异常安全基础
3. **RAII**
   - 用对象生命周期管理文件、锁和动态资源
   - 资源获取失败时的状态设计
   - 析构函数不抛异常的原则
4. **继承与多态**
   - 基类、派生类、虚函数和纯虚函数
   - 抽象类、接口、虚析构函数
   - 对象切片、动态绑定和安全向下转换
   - 组合优于继承
5. **类设计**
   - 运算符重载的合理范围
   - 依赖注入基础
   - 单一职责、低耦合和接口隔离
   - PImpl 作为进阶了解内容

## 实践任务

- 编写一个 RAII 文件封装类，禁止意外拷贝并支持移动。
- 为传感器定义抽象接口，使用两个模拟实现演示多态与依赖注入。
- 把上一阶段的缓冲区重构为拥有明确不变量的类。

## 完成标准

- [ ] 能解释对象从构造到析构的完整生命周期
- [ ] 能正确实现或禁用拷贝与移动操作
- [ ] 能解释 Rule of Zero / Three / Five
- [ ] 能用 RAII 管理至少一种真实资源
- [ ] 能说明何时用组合、继承或模板
- [ ] 能识别对象切片和非虚析构带来的问题
