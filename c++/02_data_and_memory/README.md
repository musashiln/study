# 02 - 数据、内存与底层表示

## 阶段目标

理解数据如何存放在内存中，掌握数组、字符串、引用和指针，并能识别常见内存错误。现代 C++ 中要理解裸指针，但尽量不让裸指针负责资源所有权。

## 学习内容

1. **复合数据**
   - C 风格数组、二维数组和连续内存布局
   - `std::array`、`std::string` 与 C 字符串
   - `struct`、枚举和简单数据建模
2. **引用与指针**
   - 地址、解引用、指针算术、空指针
   - 引用与指针的区别
   - `const` 与指针组合的含义
   - `std::span` 作为非拥有连续视图（C++20 提升内容）
3. **存储与生命周期**
   - 自动、静态和动态存储期
   - 栈、堆、静态存储区的概念
   - `new/delete` 的工作方式及其风险
   - 内存泄漏、重复释放、越界、悬空指针和野指针
4. **拷贝和数据布局**
   - 浅拷贝与深拷贝
   - 大小端、字节、位运算和补码
   - 整数宽度、溢出、浮点表示与精度
   - 对齐、结构体填充和 `sizeof`
5. **安全检查**
   - 未定义行为、实现定义行为
   - AddressSanitizer 与 UndefinedBehaviorSanitizer
   - 调试器中的内存和调用栈观察

## 实践任务

- 实现一个不依赖容器的定长传感器采样缓冲区。
- 打印结构体各字段地址，观察对齐和填充。
- 故意构造越界和悬空指针示例，并用 Sanitizer 定位；危险示例只放在专用练习中。
- 解析一个包含大小端整数、标志位和校验字段的字节数组。

- [ ] 能解释栈、堆、存储期与对象生命周期
- [ ] 能识别越界、泄漏、悬空和重复释放
- [ ] 能解释浅拷贝、深拷贝、大小端和结构体填充
