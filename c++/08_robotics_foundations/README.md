# 08 - 机器人数学与控制基础

## 阶段目标

为 TF2、里程计、导航、机械臂和底盘控制建立必要的数学与控制基础。重点是能用代码计算、仿真和验证，而不仅是记公式。

## 学习内容

1. **数学工具**
   - 向量、矩阵、点积、叉积和矩阵乘法
   - 线性方程、逆矩阵、特征值概念
   - 三角函数、弧度、数值误差
   - 数值微分、积分和离散时间
2. **坐标与姿态**
   - 坐标系、位置和姿态
   - 二维/三维旋转矩阵
   - 欧拉角、四元数及其优缺点
   - 齐次变换矩阵、变换组合与逆变换
3. **移动机器人运动学**
   - 速度、加速度和角速度
   - 差速底盘正/逆运动学
   - 编码器、轮速、位姿和里程计
   - 采样周期、累计误差和滑移
4. **信号与状态估计入门**
   - 噪声、偏置、漂移和采样
   - 滑动平均、低通滤波
   - 传感器融合概念
   - 卡尔曼滤波的状态、预测和更新直觉
5. **控制基础**
   - 开环与闭环
   - 比例、积分、微分和 PID
   - 饱和、积分抗饱和、噪声与微分项
   - 阶跃响应、超调、稳态误差和调参
6. **方向扩展**
   - 移动机器人：路径、定位和规划概念
   - 机械臂：关节空间、末端位姿、正逆运动学概念

## 实践任务

- 编写二维坐标变换和四元数转换测试。
- 模拟差速小车，根据左右轮速度积分位姿。
- 对带噪传感器数据实现滑动平均和低通滤波。
- 仿真 PID 控制一个一阶对象，比较不同参数下的响应。
- 计算编码器脉冲到轮速、里程计的完整链路。

## 完成标准

- [ ] 能进行向量、矩阵和齐次变换计算
- [ ] 能解释欧拉角、旋转矩阵和四元数的关系与限制
- [ ] 能推导并实现差速底盘运动学和里程计
- [ ] 能识别噪声、偏置、漂移并应用基础滤波
- [ ] 能实现和调试一个离散 PID 控制器
- [ ] 能用单元测试或仿真验证公式和边界条件
