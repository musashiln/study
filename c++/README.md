# C++、ROS 2 与嵌入式开发学习路线

这个工作区记录从 C++ 基础到 ROS 2、嵌入式开发以及二者系统集成的完整学习过程。路线以 **C++17 为主线、C++20 为提升**，强调“知识点学习 + 独立练习 + 阶段项目 + 验收复盘”。

```text

|-- 07_linux_systems_networking_concurrency/   Linux、操作系统、网络与并发
```

每个阶段的详细知识点和完成标准见对应目录中的 `README.md`。每一课使用独立目录，目录中包含说明文档、源代码和必要的测试。

## 推荐学习顺序

1. **00–02：编程和内存基础**——能够独立编译程序，理解数据在内存中的表示。
2. **03–05：C++ 核心能力**——掌握资源管理、标准库、泛型以及常用数据结构与算法。
3. **06–07：工程与系统能力**——能够构建、测试、调试多文件项目，理解 Linux、网络和并发。
4. **08：机器人理论基础**——理解坐标变换、底盘运动学、传感器数据和闭环控制。
5. **09：ROS 2**——完成通信、TF、仿真和移动机器人或机械臂方向的项目。
6. **10：嵌入式**——完成 MCU 外设、通信协议、实时任务与底层调试。
7. **11：系统集成**——连接 ROS 2 上位机和 MCU 下位机，完成一个可测试、可容错的机器人系统。

阶段并非完全串行：学完 `04_modern_cpp` 后，可以交替推进算法与工程实践；学习 ROS 2 时可以并行复习机器人数学；嵌入式硬件基础也可以提前做小实验。

## 编译单节课

在工作区根目录执行：

```powershell
New-Item -ItemType Directory -Force build
g++ -std=c++17 -Wall -Wextra -Wpedantic .\01_cpp_basics\lesson01_hello\main.cpp -o .\build\lesson01.exe
.\build\lesson01.exe
```

编译生成的可执行文件和构建产物统一放入 `build/`，不要与源文件混放。进入多文件阶段后，改用现代 CMake 的 target-based 写法。

## 学习方式

每个知识点至少完成以下闭环：

1. **理解**：能用自己的话解释概念、适用场景和常见错误。
2. **实现**：不复制答案，独立完成一个最小示例。
3. **验证**：开启编译警告，使用测试、调试器或分析工具验证行为。
4. **应用**：把知识点用于一个小练习或阶段项目。
5. **复盘**：在 `notes/` 中记录错误现象、原因、排查过程和解决方案。

## 通用完成标准

一课或一个项目只有同时满足以下条件才标记为完成：

- 能解释核心概念，而不只是让代码运行。
- 代码在开启 `-Wall -Wextra -Wpedantic` 时无未处理警告。
- 正常输入、边界输入和错误输入均经过验证。
- 有清晰的构建与运行说明。
- 重要逻辑有自动化测试，或有可重复的手工验收步骤。
- 没有把密钥、构建产物和平台临时文件提交到仓库。
- 完成一次复盘，并更新 `PROGRESS.md`。

## 主线技术选择

- **语言标准**：C++17 主线，C++20 提升，C++23 后续了解。
- **构建系统**：CMake；ROS 2 阶段使用 `ament_cmake` 与 `colcon`。
- **测试**：GoogleTest 或 Catch2 选择一个，ROS 2 中配合 `ament` 测试。
- **调试与质量**：GDB、Sanitizers、Valgrind（Linux）、clang-format、clang-tidy。
- **版本控制与自动化**：Git、GitHub Actions；需要可复现环境时学习 Docker。
- **嵌入式主线**：选择一种 MCU 平台深入学习，先裸机/SDK，再进入 FreeRTOS。

## 项目方向选择

ROS 2 基础完成后，不必同时深入所有方向：

- **移动机器人方向**：差速底盘、里程计、IMU、激光雷达、SLAM Toolbox、Nav2。
- **机械臂方向**：正逆运动学、MoveIt 2、`ros2_control` 硬件接口。

先完成一个方向的完整闭环，再扩展另一个方向。
