# 第 02 课：变量与基本数据类型

## 学习目标

完成本课后，你应该能够：

- 解释变量为什么需要数据类型
- 区分声明、初始化和赋值
- 使用 `int`、`double`、`char`、`bool` 和 `std::string`
- 使用有意义的变量名
- 使用 `std::cout` 输出变量
- 初步理解 `const` 常量

## 文件说明

- `main.cpp`：课堂示例和基础练习
- `practice.cpp`：完成课堂内容后使用的独立练习

## 编译与运行

在项目根目录执行：

```powershell
g++ -std=c++17 -Wall -Wextra -Wpedantic .\01_cpp_basics\lesson02_variables\main.cpp -o .\build\lesson02.exe
.\build\lesson02.exe
```
