# 学习笔记与故障记录

这里用于记录个人总结、实验结果、错题和真实故障。优先记录自己的理解与排查过程，不直接复制教程。

## 建议分类

```text
notes/
|-- concepts/       概念总结与知识对比
|-- errors/         编译、链接、运行和硬件故障
|-- experiments/    性能、并发、网络和控制实验
`-- decisions/      项目技术选择与取舍
```

需要时再创建这些子目录，不必提前制造空文件。

## 实验记录模板

实验要明确问题、变量和结论：

- 要验证的假设是什么？
- 固定了哪些条件，改变了哪些变量？
- 数据如何采集，单位是什么？
- 是否预热、重复运行并记录波动？
- 结果能支持什么结论，不能支持什么结论？
