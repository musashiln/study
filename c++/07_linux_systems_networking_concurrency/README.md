# 07 - Linux、计算机系统、网络与并发

## 阶段目标

具备 ROS 2 和机器人程序所需的 Linux 操作能力，理解进程、线程、内存和网络通信，并能够编写基本的安全并发程序。

## 学习内容

1. **Linux 开发环境**
   - 文件系统、权限、用户与组
   - Bash、环境变量、管道、重定向
   - `grep`、`find`、`sed`、`awk` 等常用工具
   - 包管理、SSH、进程管理和日志查看
   - 串口设备、权限、udev 规则和 `systemd` 基础
2. **操作系统基础**
   - 用户态与内核态、系统调用
   - 进程、线程、虚拟内存和上下文切换
   - 文件描述符、信号、管道和共享内存基础
   - 缓存、局部性和内存映射概念
3. **并发编程**
   - `std::thread`、线程生命周期
   - `mutex`、`lock_guard`、`unique_lock`
   - 条件变量、生产者—消费者
   - `future`、`promise`、`async` 和线程池概念
   - 数据竞争、死锁、活锁和锁顺序
4. **原子与内存模型**
   - `atomic`、原子操作和可见性
   - happens-before 与内存序基础
   - ThreadSanitizer
   - 无锁编程只做概念了解，不作为初期目标
5. **网络基础**
   - IP、端口、TCP、UDP、客户端/服务器
   - Socket、阻塞与非阻塞 IO
   - TCP 字节流与消息边界
   - 超时、断线、重连和心跳
   - 序列化、字节序和协议调试工具
6. **实时性基础**
   - 吞吐量、延迟、抖动和截止时间
   - 普通并发与实时系统的区别
   - 优先级、调度和避免不可控阻塞

## 实践任务

- 使用 Linux 工具定位进程、端口、日志和串口权限问题。
- 编写带界限的线程安全任务队列。
- 编写 TCP/UDP 传感器客户端与服务器，自定义消息帧。
- 加入超时、心跳、断线重连与优雅退出。
- 使用 ThreadSanitizer 找出并修复一次数据竞争。

## 完成标准

- [ ] 能在 Linux 中完成构建、调试、权限和进程管理
- [ ] 能解释进程、线程、虚拟内存和文件描述符
- [ ] 能正确使用锁、条件变量和原子变量
- [ ] 能识别数据竞争、死锁和生命周期问题
- [ ] 能实现带消息边界、超时和异常处理的网络通信
- [ ] 能说明普通并发和实时控制的差异
